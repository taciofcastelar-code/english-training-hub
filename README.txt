Sentence Building + Automatic Response — MVP V1

Arquivos:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

Como testar:
1. Abra index.html no computador para teste básico.
2. Para instalar como PWA no celular, publique esta pasta em HTTPS (por exemplo, GitHub Pages).
3. O progresso é salvo no localStorage do navegador/aparelho.

Escopo desta V1:
- 16 itens.
- Build + recognize + rapid response.
- Feedback simples.
- Microtreino por erro na própria sessão.
- Histórico mínimo local.
- Áudio TTS opcional para perguntas.

Base:
- Apostila English Challenge Units 1–34, principalmente Units 1, 4, 8, 10 e 12.
- Personalização adicional: check, assess, patient's vital signs, baseada no diagnóstico realizado na conversa.
